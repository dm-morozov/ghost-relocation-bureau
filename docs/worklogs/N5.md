# N5 · Понятные условия домов в игре

## Проблема

Карточки игровых домов показывали числа без шкалы и словесной оценки. Кнопки улучшений сообщали конечное число, но не объясняли переход от текущего состояния, выполняемое условие и причину недоступности покупки.

## Решение и реализация

Продуктовое направление задано пользователем: понятные параметры и эффект до расхода жетона. AI реализовал в пределах `src/ShiftGame.tsx`, `src/game.css`, `src/ShiftGame.test.tsx`:

- Семантический список характеристик: температура в °C, шум/свет/влажность по шкале 0–100, оценки «тихо/шумно», «темно/светло», «сыро/сухо».
- Общую памятку порогов: шум ≤ 30, свет ≤ 30, влажность ≥ 65. Пороги сверены с `ConditionsRule` текущего `domain.ts`.
- Видимый до покупки переход: шум 50/100 → 10/100, свет 60/100 → 10/100, влажность 40/100 → 85/100, выполняемое условие и цена 1 жетон. Конечные значения вычисляются через существующий `play(newGame(), upgrade)`, без изменения реальной сессии или сохранения.
- Состояния «Установлено» и «Недостаточно жетонов · нужно 1». Недоступные кнопки сохраняют читаемую непрозрачность и отличаются пунктирной рамкой.
- Пояснение длительности эффекта и его границ: до конца кампании, без дополнительных мест и изменения температуры.
- Перенос строк в кнопках и характеристиках для узких экранов; цвета наследуются от темы. Оставлены нативные кнопки и существующие стили клавиатурного фокуса. Карточки получили доступные имена по заголовкам.

Правила, баланс, `game.ts`, `domain.ts` и сохранения не менялись. Hook N1 в игру не подключался; это остаётся основному чату.

## Проверки и наблюдаемый результат

- `npm test -- src/ShiftGame.test.tsx src/game.test.ts` — 11/11 прошло (6 UI + 5 игровых). Три новых UI-теста проверяют все предпросмотры без расхода, активацию Enter с расходом ровно одного жетона и обновлением характеристики, различие установленного улучшения и покупки без жетонов с запретом расхода.
- Первый прогон выявил склеенные доступные имена соседних элементов кнопки. Добавлены явные пробелы; повторный прогон прошёл.
- `npx tsc -b` — на момент проверки ошибки TS2683 в чужом `src/AllocationPreview.test.tsx:16–17` (`this` без аннотации). Ошибок в файлах N5 диагностика не показала. Общая TypeScript-проверка пока не считается пройденной.
- Prettier применён только к трём файлам N5. `git diff --check` для них прошёл.
