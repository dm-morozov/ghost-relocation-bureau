# N9 · Игровой баланс и живой плейтест

## Проблема

Нужны проверка понятности и интереса трёх смен реальным пользователем и фактические основания для решений по балансу. Автоматическое прохождение не заменяет отзыв. Работа ограничена `docs/playtest.md`, этой записью и новым `scripts/analyze-game.mjs`; чужие незакоммиченные изменения сохранены.

## Решение и реализация

По поручению пользователя подготовлен сценарий на 10–15 минут: самостоятельные три смены, объяснение ожиданий перед подтверждением, необязательная гипотеза на повтор, шесть нейтральных вопросов и незаполненный лист наблюдения. Живого участника в этой работе нет; подсказки и неполное прохождение требуется фиксировать отдельно.

AI выполнил анализ реальных правил `game.ts`/`domain.ts` через `play`, без изменения `src`, новых зависимостей, браузерного сохранения, commit/push/deploy. Добавлен воспроизводимый скрипт с проверками ожидаемых исходов и replay. Продуктовые решения о числе жетонов, новых событиях и изменении интерфейса не принимались; предложения переданы в документе для интегратора, публичный Worklog не менялся.

## Проверки и наблюдаемый результат

- `node scripts/analyze-game.mjs`: пять стратегий и шесть перестановок полного расселения; все assertions и replay прошли.
- `npm test -- src/game.test.ts`: 5/5 тестов прошли. `npx prettier --check scripts/analyze-game.mjs docs/playtest.md docs/worklogs/N9.md`: все три файла соответствуют форматированию; форматирование применялось только к собственным файлам.
- Разумный план: 6/6, 476 очков; советник без улучшений: 0/6, 0 очков и три неистраченных жетона; все улучшения в одном доме: 2/6, 172; два тихих дома: 4/6, 336; пропуск первой смены с двумя улучшениями второй: 4/6, 320.
- Полное расселение даёт 460 или 476; два лучших плана равноценны. Максимум 476 обоснован шестью вариантами и отдельным ограничением для частичного расселения, а не заявлением о переборе всех нажатий.
- Найдены вопросы для интегратора: шкала 600 недостижима; предложение повысить комфорт после 476 невыполнимо; поздние улучшения не пересчитывают уже полученные очки. Общие файлы не исправлялись.

## Результат и ограничения

Автоматическая часть N9 и сценарий готовы. **N9 как пользовательская проверка не закрыта:** плейтест не проведён, отзывов, оценок интереса и фактической длительности нет. Перед живой сессией нужна текущая интегрированная сборка; данный анализ не подтверждает внешний вид и понятность изменяемого параллельно UI. Изменять баланс по одному лишь симулятору не предлагается.
