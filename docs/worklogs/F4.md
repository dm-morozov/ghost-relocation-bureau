## Findings для интегратора

1. Подтверждённых технических blockers тестов/сборки baseline нет. Транзитных падений тестов/TypeScript при этом проходе не наблюдалось.
2. Check запускает `npm ci`, test, format:check и build. Deploy Pages запускается параллельно, сам проверяет test/build, но не format:check и не зависит от Check. Поэтому для конкретного будущего SHA нужно дождаться успеха **обоих** workflow; зелёный Deploy сам не доказывает зелёный Check. Workflow F4 не меняет.
3. Готовые WebP входят в исходники, `sharp` нужен лишь для регенерации; обычной сборке дополнительных пакетов не требуется. Vite `base: './'` соответствует Pages в подпапке; nginx имеет SPA fallback, compose слушает только loopback.
4. `artifacts/` игнорируется: локальные QA evidence N7/N8 не попадут в commit автоматически. Не добавлять всю папку принудительно. Публичные документы должны честно описывать доступность evidence; нужные публикационные материалы отбирать отдельно.
5. В прочитанном IMPLEMENTATION ещё сосуществовали актуальные 167 тестов и исторические 97. F3/интегратор должен согласовать финальные статусы/числа после изменений, не выдавать старые числа за последний прогон. Содержимое N7/N9 сохраняет ограничения: реальный PDF не получен, живой плейтест не проведён. По текущему поручению это не обязательные blockers MOX; не заявлять их выполненными.
6. Журнал N8 подтверждает предыдущие браузерные проверки, но не новый F-этап: system-dark/reduced-motion runtime, 200% zoom и полный keyboard/нетекстовый контраст остаются ограничениями. Приёмку после F1/F2/F3 и логотипа проводит главный чат на фактическом финальном коде.
