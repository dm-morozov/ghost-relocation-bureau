# Параллельная разработка

Пользователь поручил выполнять N1–N9 в отдельных чатах и усилить публичный AI Worklog. Каждый чат ведёт собственную короткую запись в docs/worklogs/ со своей задачей. Основной чат интегрирует общие файлы, выполняет финальную приёмку и обновляет статусы.

Работа идёт в общем локальном checkout с незакоммиченными изменениями предыдущей итерации. Не сбрасывать чужие изменения, не делать commit/push/deploy из отдельных чатов. Не запускать других агентов без необходимости. Владелец App.tsx, README.md, IMPLEMENTATION.md и общего style.css — основной чат. Другие чаты готовят изолированные модули или предложения по интеграции.

## Формат записи по задаче

Проблема → принятое решение → реализация → проверка и наблюдаемый результат → оставшиеся ограничения. Отделять авторские продуктовые решения от работы AI. Не придумывать время, токены, пользовательские отзывы или публикацию. В публичном Worklog выделять сильные решения и исправленные ошибки; внутренние технические подробности остаются в задачах.

Все чаты запускаются по прямому запросу пользователя. N7/N8 сначала готовят сценарии и доступные проверки; повторный проход после интеграции запускает основной чат. N9 не считается пользовательской проверкой без реального отзыва.
